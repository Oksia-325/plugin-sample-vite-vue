## 2. 技术方案

### 2.1 样式体系

设计稿是 Tailwind CDN 原型，**不引入 Tailwind**（插件包体积 + 与思源主题冲突风险）。改为：

- `src/styles/pigo-tokens.scss`：设计 token → CSS 变量
- `src/styles/pigo-ui.scss`：按钮 / 卡片 / chip / 开关 / 手风琴 / 弹窗的公共类
- 组件内 scoped SCSS 只写布局

设计 token（暗色）：

```
--pigo-bg:#141417  --pigo-panel:#19191d  --pigo-card:#1f1f24
--pigo-surface:#25252b  --pigo-border:#2e2e36  --pigo-border-strong:#3a3a44
--pigo-accent:#f97316  --pigo-accent-hover:#ea580c
--pigo-purple:#8b5cf6  --pigo-blue:#3b82f6  --pigo-cyan:#06b6d4
--pigo-emerald:#10b981  --pigo-rose:#f43f5e
```

主题兼容策略：

- 面板背景 / 文本 / 边框优先使用思源变量（`--b3-theme-background`、`--b3-theme-on-background`、`--b3-theme-surface`、`--b3-theme-surface-lighter`），设计色作为 fallback；
- 语义色（橙/紫/绿/红）固定使用设计色，保证状态识别一致；
- 亮色主题下降低卡片对比度，不写死 `#000`。

### 2.2 组件改造

| 新组件 | 用途 | 说明 |
|---|---|---|
| `components/ui/PigoButton.vue` | primary / secondary / ghost / danger / icon | 替代 `b3-button` 混用 |
| `components/ui/PigoSwitch.vue` | 自动监控、设置开关 | 受控 + `aria-checked` |
| `components/ui/PigoChip.vue` | 筛选 chip、摘要 chip、状态徽章 | `tone` 枚举 |
| `components/ui/PigoCard.vue` | KPI 卡、图片卡、列表卡 | hover 抬升 1px |
| `components/ui/PigoAccordion.vue` | 设置页三块 | 默认收起、保留展开状态 |
| `components/ui/PigoModal.vue` | 清理确认弹窗 | 遮罩 + 焦点陷阱 + Esc |
| `components/ui/PigoHealthDot.vue` | S3 连接状态点 | ok / error / checking |
| `components/PigoStatusBar.vue` | 页脚：存储桶 / 模式 / 版本 | 四页共用 |

保留 `components/SiyuanTheme/*` 不动（仍被旧结构引用时可回退）。

### 2.3 布局尺寸

- 面板：`width: min(1000px, 100vw - 16px)`，`height: min(760px, 100vh - 16px)`，圆角 16px，`box-shadow` 深投影；
- 顶栏：高 52px，左「Logo + 标题 + Tabs」，右「自动监控 / 置顶 / 关闭」；拖动靠按住顶栏空白区域；
- 页脚：高 34px，`S3 存储桶: xxx (region)` + 当前模式 + `vX.Y.Z`；
- 窄屏（<720px）：KPI 2 列、卡片 1 列、页脚只留存储名。

### 2.4 防闪烁策略（针对历史问题「页面内容刷新不及时 / 动画闪烁」）

1. Tab 一律 `v-show`，绝不 `v-if` 重建；
2. 重新扫描时**保留上一份快照**，只在顶部显示进度条，不把列表清空；
3. 列表容器 `scrollbar-gutter: stable`，避免滚动条出现/消失导致横向抖动；
4. 进度条高度固定占位，完成后平滑淡出（`opacity` 过渡，不做 `height` 动画）；
5. 搜索输入 150ms 防抖；
6. 切换文档时先刷新标题，再异步替换列表，避免空态闪一下；
7. 所有 `@click` 立即触发 `loading` 态，禁止重复点击。

### 2.5 状态与缓存

- 新增 `configRevision`（配置保存成功 +1），统计 / 同步 / 健康检查监听它失效；
- 健康检查结果缓存 60s；
- 图片尺寸（`size/ext`）按可视区懒加载，缓存 Map，失败不重试。

5. 资源尺寸懒加载：`assetMeta.ts`（`Range: bytes=0-0` + `Content-Range`），S3 图先反查 fileMap 的 originUrl。

**任务**

## 7. 风险与回滚

| 风险 | 说明 | 应对 |
|---|---|---|
| 设计稿是固定暗色 | 思源亮色主题下对比度不足 | token 用思源变量兜底，F0 就验证亮色 |
| 面板内粘贴与文档粘贴冲突 | 可能吞掉正文粘贴 | 只在 `.pigo-popup` 内接管，F2 加单测 + 手动验证 |
| 尺寸懒加载请求过多 | 全库 2000+ 图 | 只对可视卡片请求，缓存 + 并发 4 + 失败不重试 |
| 健康检查误判 | 网络抖动导致红点 | 60s 缓存 + 失败保留上次状态 + 手动刷新 |
| 清理误删 | 删除不可恢复 | 保留前缀/`_pigo_test/` 保护 + 勾选确认 + 删除前 ETag 复核 |
| UI 重写导致功能回退 | 四个 Tab 全改 | 每 Phase 单独提交，F0 先只换外壳，逐页替换 |
