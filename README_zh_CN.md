# Icon8Sync

将 [Icons8](https://icons8.com/) 个人收藏夹中的图标同步到思源笔记表情库（`data/emojis/`）。

## 功能

- **增量同步**：只处理线上新增了图标的收藏夹
- **全量同步**：处理全部收藏夹，仍遵循「跳过已同步图标」设置
- **收藏夹总览**：打开弹窗即可查看收藏夹总数、本地数量、待同步数量和失败数量
- **单收藏夹重试**：只重试失败的收藏夹，不必重新同步全部
- **状态持久化**：上次同步时间、失败卡片、精确进度在关闭弹窗后仍会保留
- **白天 / 黑夜主题**：自动跟随思源主题
- **一键登录（Linux 桌面端）**：通过临时无头 Firefox 配置读取本机 Icons8 登录状态
- **测试连接**：不保存配置即可验证 Token
- **自动选择代理**：Icons8 API 优先走系统代理，失败时自动回退思源内核代理
- **缓存选项**：可跳过已同步图标，也可选择同步后自动刷新表情列表
- 并发下载限流、文件名净化与 `(1)` 式重名去重
- 收藏夹映射为小写表情分组目录，同步后即可在思源表情面板中使用

`Favorites` 和 `Downloaded` 收藏夹会被忽略。同步是单向的：只存在于本地的图标不会被删除或处理。

## 环境要求

- 思源笔记 3.8.1 或更高版本
- Icons8 账号
- 一键登录仅支持 **Linux 桌面版思源**，并且本机 **Firefox 已登录 icons8.com**
  - Windows 及其他平台会提示手动粘贴 Token

## 使用

1. 启用插件后，点击顶栏图片图标，或打开 `设置 → 市场 → Icon8Sync → 设置`。
2. 在「设置」页配置 Token：
   - 手动获取：登录 icons8.com → 按 F12 → Network 面板 → 任选一个请求 → 复制请求头 `Authorization` 的值（可去掉 `Bearer ` 前缀）。
   - Linux + Firefox：点击「一键登录」自动读取当前 Firefox 登录状态。
3. 可先点「测试连接」验证，再点「验证并保存」。
4. 切到「同步」页：
   - 日常使用点「开始增量同步」。
   - 需要处理全部收藏夹时点「开始全量同步」。
   - 失败卡片可单独点击「重试」。

## 选项说明

| 选项 | 说明 |
| --- | --- |
| 跳过已同步图标 | 只下载本地缺失的图标。关闭后，全量同步会重新下载全部图标。 |
| 自动刷新图标缓存 | 同步完成后立即刷新表情选择器。关闭后需手动重启思源。 |
| 自动选择代理 | Icons8 API 优先使用系统代理，直连失败时自动回退思源内核代理。 |

## 说明

- 增量同步通过「线上图标总数」与「本地清单数量」判断收藏夹是否变化。如果线上只是替换了图标、数量未变，增量同步不会发现，请使用全量同步。
- 一键登录会把最新的 Firefox Cookie / 配置文件复制到临时目录，启动无头 Firefox 读取 Token，结束后自动删除临时目录。Token 不会写入日志或上传到其他服务。
- 如果经常出现 `Icons8 API request failed (forwardProxy)`，可在设置中开启「自动选择代理」。
- 插件不会删除本地独有的表情文件。

## 开发

```bash
pnpm i
cp .env.example .env   # 设置 VITE_SIYUAN_WORKSPACE_PATH
pnpm dev               # 监听构建到 <workspace>/data/plugins/icon8-sync
pnpm build             # 产出 dist/ + package.zip
```
